# 🀄️ 雀聖AI (Mahjong Master Pro)

プロ競技麻雀標準ルール準拠の本格麻雀Web/PWAアプリケーション。  
点数計算・待ち牌＆シャンテン数ナビ・スマホカメラ手牌OCR認識の3大機能をワンストップで提供します。

---

## 🌟 主な機能

### 1. 🧮 本格点数計算 (Score Calc)
- **4面子1雀頭の高点法判定**: 刻子・順子・対子の組み合わせを全探索し、最高得点の分解を自動採用。
- **符計算の完全対応**: 副底20符、門前加符10符、ツモ2符、雀頭役牌符2符、明刻/暗刻/明槓/暗槓の幺九・中張符、待ち符（単騎・嵌張・辺張 2符）、平和ツモ20符固定、七対子25符固定。
- **全役判定（1翻〜役満）**:
  - 立直・一発・門前ツモ・タンヤオ・平和・役牌（白/發/中/場風/自風）・一盃口・チャンタ・三色同順・一通
  - 七対子・対々和・三暗刻・三槓子・混老頭・小三元・ダブル立直・純チャン・混一色・二盃口・清一色
  - 役満: 四暗刻（単騎）、大三元、字一色、緑一色、清老頭、国士無双（13面）、九蓮宝燈（純正）、天和、地和
- **詳細内訳表示**: 翻・符・ランク（満貫・跳満・倍満・三倍満・役満）、ツモ/ロン時の支払い点数（親/子、本場加算、供託受取）、成立役一覧、符内訳、面子構成分解。

### 2. 🎯 待ち牌・待ち数・シャンテン数ナビ (Wait & Shanten)
- **リアルタイム判定**: 牌をタップするごとにシャンテン数（一般手、七対子、国士無双）を即時計算。
- **待ち牌ビジュアル一覧**: テンパイ時にアガリ牌を立体牌で一覧表示。
- **残り牌数（待ち数）メーター**: 自分が使っている牌数から残り枚数を自動算出し、視覚的バーで表示。
- **待ち形状判定**: 両面（リャンメン）、嵌張（カンチャン）、辺張（ペンチャン）、単騎（タンキ）、双ポン（シャンポン）、ノベタン、3面張、多面張を自動判別して解説。
- **打牌アシスト（何切る？）**: 14枚持っている時、どの牌を切るとシャンテン数がどう変わり、何枚受け入れられるかをシミュレーション表示。

### 3. 📷 手牌OCRカメラ認識 (Camera Scanner)
- **スマホカメラ連携**: `getUserMedia` によるカメラ起動、または画像ファイル（PNG/JPG）アップロード。
- **手牌セグメンテーション**: ガイド枠に合わせて並べた手牌を14分割して自動切り出し。
- **画像特徴解析**: 色相（萬子・筒子・索子・字牌）および幾何学的パターンによる牌種判別。
- **クイック修正UI**: 認識結果の手牌トレイから牌をタップして修正可能。
- **ワンタップ連携**: 「点数計算へ」「待ち牌ナビへ」ボタンで即座に解析へ移動。

### 4. 🀄️ 雀卓風モダンUI/UX & PWA
- **雀卓マット調デザイン**: 深緑フェルト質感、高級木枠、リアルな立体牌レンダリング（SVG & 陰影）。
- **モバイル最適化**: 画面下部に固定された押しやすい牌パレット。
- **PWA（Progressive Web App）**: スマホの「ホーム画面に追加」で全画面ネイティブアプリ同様に利用可能。オフライン動作対応（Service Workerキャッシュ）。

## 🚀 起動方法

### ブラウザで開く（最もシンプル）
`public/index.html` をお好みのブラウザ（Google Chrome, Safari, Edgeなど）で直接ダブルクリックして開くか、以下のコマンドでローカルサーバーを起動します。

```bash
cd /Users/notsujunzou/Desktop/mahjong-app/public
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` にアクセスしてください。
